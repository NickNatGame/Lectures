
###### Вход задачи - объект - то что анализируем (буква X)
Пространство объектов - $\mathbb{X}$ 

###### Выход - ответ или целевая переменная (target) - то, что оцениваем или прогнозируем
Пространство ответов - $\mathbb{Y}$ 

###### Обучающая выборка - это объекты для которых мы знаем правильные ответы
Размер выборки - $\ell$

Data drift - явление, что данные могут меняться

###### Признаки (факторы/features/фичи) - характеристики объектов
Какие бывают признаки:
1. Числовые x $\in$ $\mathbb{R}$ - gpa, зп или посещение
2. Категориальные признаки - его значения берут из некоторого множества, где умеем только сравнивать на равенство - образовательная программа, знак зодиака, поток студента
3. Set-valued - когда признак принимает значения подмножества множества
4. Порядковые признаки - как категориальные, но есть операция сравнения - курс студента, грейд на работе, размер футболки
Разница порядковых и числовых - то, что порядковые не поддаются арифметике 
Глубинное обучение / Deep Learning - как обойтись без ручного придумывания признаков
###### Тип задачи - определяется $\mathbb{Y}$ (целевой переменной)
1. Обучение с учителем (supervised learning) - есть целевая переменная
	1. $\mathbb{Y}$ $\in$ $\mathbb{R}$ - регрессия (предсказание оценки студента)
	2. |$\mathbb{Y}$| < $\infty$ - классификация (мощность множества ответов - конечное)
		1. $\mathbb{Y}$ = ${0,1}$ - бинарная классификация (отчислится / не отчислится)
		2. $\mathbb{Y}$ = ${1, ... ,K}$ - много классовая классификация (multi - class) (по студенту предугадать какую специализацию возьмет)
		3. $\mathbb{Y}$ = ${{0, 1}^k}$ - классификация с пересекающимися классами (multi - label) (если выбираешь какая болезнь у человека, их может быть несколько одновременно) P.S. мы имеем ввиду что классы не ортогональны (не независимы) - т.е. классы каким - то образом скоррелированы 
	3. Ранжирование (есть запрос и есть база - надо отсортировать всю базу)
2. Обучение без учителя (unsupervised learning) - нет целевой переменной
	1. Кластеризация:
		$\mathbb{X}$ - надо разбить на какие то подмножества, чтобы объекты были похожи внутри подмножеств
	2. Оценивание плотности (поиск аномалий)![[аномалия.png]]
3. Обучение с подкреплением (Где мы делаем условно награду модели)
4. Частичное обучение (данных много но только у части есть правильные ответы, а остальные не размечены)
5. и т.д.

###### Модель или алгоритм - функция, которая принимает что то из пространства объектов $\mathbb{X}$ и возвращает что то из пространства ответов $\mathbb{Y}$ :
$\mathbb{a}: \mathbb{X} \to \mathbb{Y}$ 
$\mathbb{a}(x) \sim y$ 
пример: $\mathbb{a}(x) = \mathbb{w_{0}} + \mathbb{w_{1}}\mathbb{x_{1}} + \dots + \mathbb{w_{d}}\mathbb{x_{d}}$ - линейная модель

Модели бывают:
1. Дифференцируемыми
2. Не дифференцируемыми
$\mathbb{A} =$  { ${\mathbb{a}(\mathbb{x}, \mathbb{w} )  |  \mathbb{w}}$ } - семейство моделей

Функция потерь (loss function):
$\mathbb{L}: \mathbb{Y} \times \mathbb{Y} \to \mathbb{R_{{+}}}$ 
$\mathbb{L}(\mathbb{y}, \mathbb{z})$, где $\mathbb{y}$ - правильный ответ, $\mathbb{z}$ - ответ модели
т.е. говорит, насколько модель неправа (всякие MSE, MAE и т.д.) 
Через loss мы задаем требование к модели

Q( a, X ) - функционал ошибки (функционал качества)
в большинстве случаев:
Q( a, X ) = $1/\ell \sum_{i=1}^{\ell} \mathbb{v_{i}}\mathbb{L}(\mathbb{y_{i}, \mathbb{a}(\mathbb{x_{i}})})$, где $\mathbb{v_{i}}$ - веса объектов

Обучение модели - выбор такой модели из нашего семейства, где достигается минимум функционала ошибки
