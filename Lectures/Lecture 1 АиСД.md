**инвариант цикла** — это условие, предикат $P$, истинность которого сохраняется при инциализации, при выполнении тела, а также при завершении цикла
#### важно отметить
- общего способа поиска нварианта для любого цикла найдено не было
- инвариант, интуитивно, отражает природу вычислений внутри цикла:  
    какова цель / что уже вычислено / что осталось вычислить
- для поиска инварианта можно использовать трассировку цикла
### алгоритм сортировки вставками (insertion sort)
```
#include <vector>
void insertion_sort(std::vector<int>& arr) { 
    int n = arr.size();
    for (int i = 1; i < n; ++i) {  
        int key = arr[i];
        int j = i - 1;  
        while (j >= 0 && arr[j] > key) {
            arr[j + 1] = arr[j];
            j = j - 1; 
        }
        arr[j + 1] = key;
    }
}
```
#### утверждение 01.01
для любого массива arr длины n≥1n≥1 верно, что алгоритм insertion_sort упорядочит элементы входного массива в порядке возрастания
условие упорядоченности: $∀i∈[0,n−2]:arr[i]≤arr[i+1]$ 

### алгоритм факториала
```
#include <iostream>
unsigned long long factorial_loop(int n) { 
    if (n < 0) return 0;
 
    unsigned long long fact = 1;
    for (int i = 0; i <= n; ++i) {
        fact *= i;
    }
 
    return fact;
}
 
int main() {
    std::cout << factorial_loop(5);
    return 0;
}
```
#### утверждение 01.02
для любого целого неотрицательного числа nn верно, что алгоритм factorial_loop возвращает корректное значение $n!$
условие корректности: $∀n≥0:fact=n!$
#### доказательство
корректность вычисления факториала опирается на инвариант цикла for:
$P={∀i∈[0,n]:fact=(i−1)!}$
то есть, переменная factfact хранит промежуточный факториал
- INIT — начальное значение     
    fact и счетчика fori=1⇒fact=(i−1)!=0!=1⇒i=1⇒fact=(i−1)!=0!=1⇒  
    инвариант $p$ тривиально выполнен
- MNT — пусть перед $i$-ой итерацией     
    выполняется $fact=(i−1)!$:
    $fact=fact⋅i=(i−1)!⋅i=i!$
    $i=i+1⇒fact=i!=((i+1)−1)!$
- TRM — выход из  
    основного цикла for  
    $i=n+1⇒fact=((n+1)−1)!=n!⇒$
    факториал вычислен

#### алгоритм GCD
```
#include <iostream>
int gcd_euclidean(int a, int b) { 
    if (a = 0) return b;
    if (b = 0) return a;
 
    while (a != b) {
        if (a > b) a -= b;
        else       b -= a;
    }
 
    return a;
}
 
int main() {
    std::cout << gcd_euclidean(104, 24);
    return 0;
}
```
#### утверждение 01.03
для любой пары целых неотрицательных $a$ и $b$ верно, что алгоритм gcd_euclidean возвращает значение их наибольшего общего делителя
условие корректности: $∀a,b⩾0:a=GCD(a,b)$
#### доказательство
корректность вычисления НОДа опирается на инвариант цикла while:
$P={GCD(a,b)=GCD(a0,b0)}$,
где $a_{0}$​ и $b_{0}$​ — начальные значения aa и bb
- INIT — совпадение  
    с исходными значениями   
    $a=a_{0},b=b_{0}⇒$
    $GCD(a,b)=GCD(a_{0},b_{0})$
- MNT — пусть перед итерацией      
    $GCD(a,b)=GCD(a0,b0)$
    $a>b⇒GCD(a−b,b)=GCD(a,b)$
    $b>a⇒GCD(a,b−a)=GCD(a,b)$
- TRM — значения переменных сравнялись
    $a=b⇒$  
    $GCD(a,a)=a=GCD(a_{0},b_{0})$
