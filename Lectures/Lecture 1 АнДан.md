#### Источники данных для анализа:
- Kaggle
- Google Dataset Search
- Awesome Data
Также собирать данные можно при помощи Webscrapping или API. 
API - более официальный вариант, можно скачивать данные по регистрации

Еще есть Краудсорсинг данных, через онлайн платформы, к примеру CAPTCHA. 

Синтетические данные - искусственно созданные данные, которые можно собирать при помощи, к примеру, нейросетей.
Можно использовать, когда:
- Показываем работу продукта
- Когда тестируем алгоритм, как он будет в принципе работать
- Расширение уже существующего датасета, генерируя по метрикам реальных данных

### Типы данных и их структура
- Перекрёстные данные (cross-sectional data) - прямо щас, прямо здесь, взяли и собрали данные
- Временные данные (time series data) - проверка время от времени, к примеру курс доллара к рублю
- Панельные данные (panel data) - данные, которые по времени имеют одни и те же фичи, к примеру данные в больницах
